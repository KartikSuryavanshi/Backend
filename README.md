#  A mini project using Node.js & Express.js
 This web application, built with Node.js and Express.js, features:

User Creation: Register new users with essential details including name, email, and profile image.
User Management: View all registered users in a dedicated route, displaying their profile images and basic information.
Route Navigation: Seamlessly navigate between different routes to manage users and their profiles.
The system provides an intuitive interface for managing user information and navigating between different views effortlessly.
