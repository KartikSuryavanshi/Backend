## 📌 About This Repository
This repository contains a **backend-focused mini project** built using **Node.js** and **Express.js**, aimed at understanding **core backend concepts** and **server-side development workflows**.

The project demonstrates how to:
- Create and manage users
- Handle routes and views
- Work with backend logic and templating
- Organize backend project structure effectively

Along with the project code, this repository also includes a **Backend Core Concepts PDF** for theoretical understanding.

---

## 🚀 Project Overview
This web application allows:

- **User Creation**
  - Register new users with basic details such as name, email, and profile image

- **User Management**
  - View all registered users on a dedicated route
  - Display user information along with profile images

- **Route Navigation**
  - Navigate seamlessly between routes
  - Render dynamic pages using templates

- **MVC-style Structure**
  - Models for data logic
  - Views for UI rendering
  - Public assets for styling

## ▶️ How to Run the Project
1. Clone the repository
2. Navigate to the project directory
3. Install dependencies:
   npm install
4. Start the server:
   node index.js
5. Open your browser and visit:
   http://localhost:3000
